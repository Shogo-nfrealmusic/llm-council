## Question (as asked)
東京で訪日観光客向けのフォトスタジオをやっています。来月Instagram広告に50万円入れます！絶対当たると思う。予約単価は2万円、サイトのCVRは1.2%、広告のCPAはまだ測ったことがない。いいよね？

## Brief
決定: 東京で訪日観光客向けフォトスタジオを運営する事業者が、来月Instagram広告に50万円を投下するか、しないか、または規模・方法を変えるか。
事実: 予約単価2万円。サイトのCVR 1.2%。広告のCPAは未測定。
未検証の主張: このInstagram広告は採算が合う（成果が出る）。
不明: 粗利率、広告のクリック単価、ターゲット国・言語、現在の予約数と撮影枠の余力、過去の広告実績、計測体制。

取り除いた言い回し: 「絶対当たると思う」「いいよね？」「！」

## Chairman
VERDICT: CHANGE IT — まず10万円で試し、結果で残りを決める
理由:
- 粗利率もCPA(予約1件の広告費)も不明で、50万円の採算は計算不能。
- 「採算が合う」は未検証。1.2%はサイト平均で広告流入は低めが普通。
  損益分岐はCPA=2万×粗利率、CPC=240円×粗利率(逆張り・拡張)。
最大のリスク: 10万円では件数が少なく、伸びる広告を早く切ること。
次の3ステップ:
1. 10/3までに粗利率と空き枠を出し、予約完了をMetaで計測
   — 成功: テスト予約が管理画面に出る / 中止: 計測不可なら出稿しない
2. 10/4〜17に10万円、1国1言語で配信 — 成功: CPA≦2万×粗利率
   / 中止: 損益分岐CPAの2倍を使って予約0件なら停止(目安)
3. 10/18に判定、残り40万円は勝った国・言語へ — 成功: CPA基準内
   / 中止: CPAが基準超、または枠が埋まり既存客と重なる
判断が変わる条件: 過去の計測済み広告でCPAが損益分岐以下なら全額GO
---DETAILS---
論点の核心: 計測できない状態で、50万円に見合う予約が来ると言えるか。売上2万円の予約が25件で費用とやっと同額になり、粗利で見るとさらに多くの件数が必要です。
意見が割れた点: 全額を出すGOはレッドチームだけでした。残る5人は少額テストで一致しましたが、額は違います。第一原理・実行・部外者は5〜10万円、逆張りは約10万円、拡張は15万円でした。10万円にしたのは、粗利率50%なら損益分岐CPAが1万円になり、約10件分の判断材料が取れるからです(目安)。
レッドチーム: 主張は2つでした。「日ごとに止められるので、少額テストと全額投下は実質同じ」と「少額ではMetaの学習(配信の自動最適化)が終わらない」です。どちらも判断は変えませんでした。まず、止めるにはCPAの実測値が要ります。計測が整っていなければ、止め時を決める根拠がありません。次に学習の件数です。粗利率50%で全額を使っても予約は月50件ほどで、Metaの目安とされる週50件(概算)には全額でも届きません。このため学習の論点はどちらの案が有利かを分けません。CPC80円・粗利60%という試算も推定です。一方で、繁忙期を逃さないように、テストは10月前半に収めました。対策として、予約開始など件数の多い手前の行動で最適化すると学習が進みやすくなります。拡張の案も使えます。Klookなど成果報酬型の予約サイトとCPAを比べることと、撮影後の写真をタグ付きで投稿してもらう特典です。
重要な未知数: 1つ目は粗利率です。高ければ許容できるCPAが上がり、GOに近づきます。2つ目は10月の撮影枠の空きです。ほぼ埋まっていれば、広告自体が不要になります。3つ目は手元資金です。資料にありません。50万円を失っても困らない額なら、テストの額を増やす余地があります。

## Advisor answers

### Answer A

POSITION: CHANGE — 50万円を一度に使わず、まず計測を整え、約10万円（目安）で2〜3週間テストする。CPAを実測してから残りを判断する。
CONFIDENCE: 70%
REASONS:
- 失敗の筋書き：1.2%は検索など予約意欲の高い流入を含むサイト平均。インスタ広告の流入はこれより低く、クリック単価の上限（2万×1.2%×粗利率、粗利100%でも240円）を超えやすい。
- 計測体制が不明。予約は旅行前、別の端末で数週間後に入るため広告と紐付かない。50万円を使っても効果を判定できない。
- 売上だけで回収するにも25件（50万÷2万）が必要で、粗利ベースではさらに多い。空き枠が不明なら、既存客の置き換えで終わる。
AGAINST MY POSITION: 旅行前の検討期間は長く、少額で短いテストは効果を過小評価し、有望な集客経路を捨てかねない。
KEY POINT OTHERS WILL MISS: 停止基準は「CPA＞2万×粗利率」。粗利率が不明なままでは、この基準すら決められない。


### Answer B

POSITION: CHANGE — 50万円全額投下ではなく、5〜10万円規模の小額テストでCPAと粗利率を先に測定すべき。
CONFIDENCE: 72%
REASONS:
- 前提「採算が合う」はCPAも粗利率も未測定のまま検証不能な仮説。予約単価2万円は売上であって利益ではなく、粗利率次第で許容CPAは数千円〜1万円台と大きく変わる。この数字がない限り50万円が妥当かどうか判定できない。
- CVR1.2%は「サイト訪問後」の数値であり、広告クリック単価やターゲット国・言語が不明なため、広告費→クリック→予約の変換率（真のCPA）は全く別の話。サイトCVRを広告の成果指標に流用するのは誤り。
- 撮影枠の余力が不明なら、広告で予約が増えても捌けない可能性があり、50万円が無駄撃ちになるリスクがある。
AGAINST MY POSITION: 小額テストは学習速度が遅く、繁忙期（インバウンド需要）を逃す機会損失の方が大きい可能性がある。
KEY POINT OTHERS WILL MISS: 問うべきは「広告すべきか」ではなく「粗利率と撮影枠の余力を先に確定できるか」という測定体制の問題。


### Answer C

POSITION: CHANGE — 50万円を一括投下せず、まず5-10万円の少額テストで実CPAと粗利率を計測してから本投下を決める。
CONFIDENCE: 72%
REASONS:
- CPA未測定・粗利率不明のまま50万円を使うのは、単価2万円×CVR1.2%という前提だけで採算判断できない致命的な穴。クリック単価とターゲット国次第でCPAが1万円を超えれば粗利を食い潰す可能性が高い。
- 来週にできる具体策: 予算5万円・1地域1言語に絞ってGA/コンバージョン計測を設定し3-5日回す。CPAと粗利率（原価データがあれば）を出す。CPAが粗利の範囲内（例:粗利率50%なら1万円未満)なら本投下、超えるなら中止か広告文・ターゲット見直し。
- 撮影枠の余力が不明なため、先に本投下すると予約殺到しても対応できない/枠が余って無駄打ちになるリスクもテストで同時に見える。
AGAINST MY POSITION: 少額テストは学習が遅く、来月の繁忙期機会を逃す可能性がある。
KEY POINT OTHERS WILL MISS: 計測体制（コンバージョンタグ・アトリビューション）が未整備なら、50万円使っても正しいCPAは得られず判断材料にならない。


### Answer D

POSITION: GO — 50万円を月予算として出稿し、日次で停止できる前提で計測しながら回すべき。
CONFIDENCE: 35%
REASONS:
- 広告費は日割りで消化され、いつでも止められる。「小額テスト」は50万円予算に停止基準を付けたものと実質同じで、別の案とは言えない。
- 5〜10万円では予約が数件しか得られない。Metaの学習期間（目安は週50CV前後、推定）を抜けられず、CPAはノイズになる。
- 例：CPC80円（推定）なら50万円で約6,250クリック。CVR1.2%で約75件、売上150万円となる。粗利60%（推定）なら損益分岐CPAは1.2万円で、実CPAは約6,700円。10万円テストの約15件では判断が揺れ、訪日の繁忙期を逃す。
AGAINST MY POSITION: 計測が整っていないまま出すと、成否をそもそも判定できない。
KEY POINT OTHERS WILL MISS: 停止基準があれば最悪の損失は数万円に収まり、「全額を失うリスク」は実在しない。


### Answer E

POSITION: CHANGE — 50万円を一括で使わず、計測を整えたうえで15万円を2週間試し、CPAが基準内なら残り35万円を追加投下する。
CONFIDENCE: 65%
REASONS:
- 1クリックあたりの売上は、2万円×1.2%=240円。クリック単価がこれを超えると、粗利を引く前から赤字になる。損益の余裕は小さいので、先に数字を掴んでから残りの予算を当たった国・言語に集中させる。そうすれば上限を気にせず拡大できる。
- 本当の上振れは予約そのものより、顧客が撮った写真の再投稿と、リターゲティング用の訪問者リストにある。撮影後にタグ付け特典を付ければ、広告費のかからない集客が積み上がっていく。
- Klookなど成果報酬型の予約サイトを並行して使えば、確定したCPAを比較基準として持てる。
AGAINST MY POSITION: 15万円では学習データが足りない。配信の最適化が終わる前に「効果なし」と誤って判断し、伸びるはずの芽を潰しかねない。
KEY POINT OTHERS WILL MISS: 撮影サービスは成果物そのものが広告素材になる。広告は予約獲得よりも、口コミの起点として評価すべきだ。


### Answer F

POSITION: CHANGE — いきなり50万円全額を投じず、まず5〜10万円程度で小さく試して数字を測ってから本投下すべき。
CONFIDENCE: 68%
REASONS:
- 粗利率もCPCも撮影枠の空きも分かっていないのに、儲かるかどうか誰も計算していない。これは「勘で50万円賭ける」のと同じで、普通の商売なら怖くてできない。
- CVR1.2%は分かっているが、広告経由の質(観光客がどれだけクリック単価が高いか)は未知数。CPAが分からないまま額を決めるのは、値段を聞かずに買い物するようなもの。
- 撮影枠に余力があるかも不明。広告で予約が増えても捌けなければ意味がない。まず「予約は増やせるのか」を安く確認するのが筋。
AGAINST MY POSITION: 小さく試すと機械学習の最適化が効かず、CPAが本来より悪く出て誤判断するリスクがある。
KEY POINT OTHERS WILL MISS: 広告費より先に「粗利率と撮影枠の空き」を確認しないと、広告が当たっても利益が出ない・予約を裁けない可能性がある。
