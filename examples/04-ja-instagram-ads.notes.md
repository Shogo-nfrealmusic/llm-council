# LLM Council — Instagram広告に50万円を投じるか

- Date: 2026-09-28 / Mode: standard / Language: Japanese
- Key: A = 実行 (sonnet), B = 部外者 (sonnet), C = レッドチーム (opus), D = 拡張 (opus), E = 第一原理 (sonnet), F = 逆張り (opus); reviewers sonnet; chairman opus

## Question (as asked)
東京で訪日観光客向けのフォトスタジオをやっています。来月Instagram広告に50万円入れます！絶対当たると思う。予約単価は2万円、サイトのCVRは1.2%、広告のCPAはまだ測ったことがない。いいよね？

## Brief
決定: 来月、Instagram広告に50万円を投じるか否か（または規模・方法を変えるか）を決める。
事業: 東京の訪日観光客向けフォトスタジオ。
事実: 予約単価2万円、サイトのCVR 1.2%、広告予算50万円（来月1か月）。
未検証の主張: このInstagram広告は成果が出る。
不明: 広告のCPA（未計測）、クリック単価、粗利率、現在の月間予約数と集客経路、訪日客へのターゲティング方法、広告経由予約の計測体制。
取り除いた言い回し: 「絶対当たると思う」「いいよね？」「！」

## Advisor answers

### Answer A

POSITION: CHANGE — 50万円を一括投下せず、まず5〜10万円で1週間の計測テストを行い、CPAと計測体制を確認してから本予算を決める。
CONFIDENCE: 75%
REASONS:
- CPAもクリック単価も粗利率も未計測のまま50万円を投じるのは、成果を判定する物差しがない状態で撃つのと同じ。CVR1.2%とCPCの掛け算だけでCPAは大きく変わり、赤字の可能性を排除できない。
- 広告経由予約の計測体制が「不明」＝そもそも成果を来月中に正しく検証できない可能性がある。トラッキング未整備なら50万円使っても「成果が出たか」自体が分からず終わる。
- 少額テストなら来月末を待たずに今週末〜来週月曜には着手・初期データ取得が可能。小さく始めて数字が出れば増額すればよく、機会損失は最小。
AGAINST MY POSITION: 少額テストは学習コストで、規模の経済（配信最適化）が働く前に判断すると本来効くはずの施策を見誤る可能性がある。
KEY POINT OTHERS WILL MISS: 「広告が効くか」より先に「計測できているか」を月曜までに確認しないと、50万円使っても来月末に何も学べない。


### Answer B

POSITION: CHANGE — 50万円を一括投入する前に、計測体制と少額テストで数字を確認すべき。
CONFIDENCE: 78%
REASONS:
- CVR1.2%・予約単価2万円は分かるのに、肝心のCPAとクリック単価、粗利率が「不明」のまま50万円を賭けるのは、値段も知らずに大量発注するようなもの。
- 広告経由予約を計測する仕組みが無いなら、50万円使っても「効果があったか」自体が分からず、来月また同じ議論をするだけになる。
- 訪日客への具体的ターゲティング方法が未定なのに予算だけ先に決まっているのは、狙いを定めずに弾を大量に買う話に聞こえる。
AGAINST MY POSITION: 訪日インバウンド需要は季節性が強く、テストで様子見している間に旬を逃すリスクはある。
KEY POINT OTHERS WILL MISS: 計測体制がない状態では50万円が5万円でも失敗の理由は同じで、金額を減らすことより先に「予約に印がつく仕組み」を作ることが本質。


### Answer C

POSITION: GO — 計測タグを整え、停止ルールを付けて50万円を1か月で投下する。
CONFIDENCE: 30%
REASONS:
- 5〜10万円で1週間のテストでは、Metaの学習期間を抜けられない。訪日客は来日の数週間前に予約するため、予約までのタイムラグで成果が出ず、「効かない」と誤判定しやすい。
- 推定CPC80円なら約6,250クリック、CVR1.2%で約75件、売上150万円。粗利率60%（推定）でも損益分岐の約42件を超える。1か月の規模でないと分岐点を判定できるだけの件数が集まらない。
- 下振れしても損失は50万円が上限で、2週目にCPAが4万円を超えたら止めればよい。
AGAINST MY POSITION: CPAも粗利も計測体制も未確認のまま、月予算の全額を賭けることになる。
KEY POINT OTHERS WILL MISS: 少額テストは安全策に見えるが、予約までのタイムラグと学習期間のせいで、実際には「判定不能」という結果を買うことになる。


### Answer D

POSITION: CHANGE — 50万円を一括で投じず、まず15万円を計測付きのテストに使い、残りはCVR改善と来日前の層への施策に回す。
CONFIDENCE: 70%
REASONS:
- 売上だけで元を取るには予約25件が必要。CVR1.2%なら約2,080クリック、クリック単価で約240円以下という計算になる（粗利を引く前の試算）。計測しなければ、当たった施策を大きくできない。
- CVRを2.4%に上げれば1件あたりの獲得費は半分になり、その後の広告費すべての効率が2倍になる。広告を増やすより効く。
- 撮影した写真がそのまま広告素材になる。顧客の投稿を再掲したり、小紅書やKlookなどで来日前に旅程を組む層へ広げたりする余地が見落とされている。
AGAINST MY POSITION: 少額のテストでは学習データが足りず、本来は勝てる広告を低く評価して機会を逃す。
KEY POINT OTHERS WILL MISS: 本当に残る資産は1か月分の予約数ではなく、「どの国の客にどの素材が効くか」という知見と、来日前に予約してもらう導線である。


### Answer E

POSITION: CHANGE — 50万円を一括投下する前に、少額でCPAと計測体制を検証すべき。
CONFIDENCE: 72%
REASONS:
- 「このInstagram広告は成果が出る」は未検証の前提であり、CPA・クリック単価・粗利率・計測体制のいずれも不明なまま50万円全額を投じるのは、成果測定不能なまま予算を燃やすリスクが高い。CVR1.2%は既存サイト全体の数値であり、Instagram広告経由の訪日客に同じ数値が当てはまる保証はない。
- 粗利率が不明なので、CPAがいくらまでなら黒字か（例えば予約単価2万円に対しCPAが1万円超なら赤字の可能性）という損益分岐点すら計算できない。この状態で意思決定するのは「予算ありき」で「目標CPAありき」ではない、順序が逆。
- 訪日客への言語・地域ターゲティング設計と広告経由予約の計測（UTM・コンバージョンタグ等）が未整備なら、50万円使っても「効果があったか分からない」結果に終わる可能性が高い。
AGAINST MY POSITION: 少額テストでは統計的に有意なCPAが出ず、時間だけロスして機会損失になるという反論はあり得る。
KEY POINT OTHERS WILL MISS: 予算配分の議論の前に、まず計測タグと損益分岐CPAを設計・確定させることが最優先である。


### Answer F

POSITION: CHANGE — 50万円の一括投入はやめ、計測を整えたうえで1〜2週間・10万円程度（推定）のテストに縮小する。
CONFIDENCE: 75%
REASONS:
- 最も起こりやすい失敗は、効果が分からないまま予算が消えること。計測体制が未整備なので、翌月には「効いたのか不明」しか残らず、判断材料にならない。
- 採算の条件が厳しい。売上だけで50万円を回収するには25件の予約が必要で、CVR1.2%なら約2,100クリック、クリック単価は約240円以下が条件になる。粗利で見ればさらに厳しい。
- 訪日客は数週間前に予約することが多い。国内の人に広告が表示されたり、旅行予定のない人に届いたりすれば、予算を使い切ってもCVRは想定を下回る。
AGAINST MY POSITION: 訪日客はInstagramで写真スタジオを探すので、少額テストでは配信の学習が進まず、機会を逃す。
KEY POINT OTHERS WILL MISS: 広告経由の予約の一部は、Googleマップや予約サイト経由の自然流入を奪っただけの可能性があり、見かけの成果が膨らむ。

## Chairman
VERDICT: CHANGE IT — 50万円は一度に全部使わず、
計測を整えてから2段階で使う（前半20万円で判定）。
論点の核心: 広告経由の予約を計測したとき、
1件あたりの獲得費（CPA）は損益分岐を下回るか。
決め手: 部外者の「計測がなければ5万円でも
50万円でも失敗の理由は同じ」。第一原理の指摘どおり、
CVR1.2%はサイト全体の数字で、広告経由の訪日客にも
当てはまる保証はない。「この広告は成果が出る」は
支持も否定もされず、未決着。
残っている最大の反論: レッドチームの言う
Metaの学習期間（配信が安定するまでの期間）と
予約までの時間差がある。20万円・2週間でも
判定できない恐れは残る。
意見が割れた点:
- レッドチーム（全額GO）対他5人（縮小テスト）
- レッドチームの主張で、5〜10万円・1週間案は捨てた
重要な未知数: 粗利率（低いほど中止寄り）、
現在の予約数と経路（逆張りの言う自然流入の奪い合い）
判断が変わる条件: 前半のCPAが損益分岐の
2万円×粗利率以下なら、残り30万円を投じる
次の3ステップ:
1. ピクセル・UTM・予約時の流入元質問を入れる
— 成功: 10/2までにテスト予約を100%記録 /
中止: 記録できなければ広告を出さない
2. 粗利率と現状の予約経路から損益分岐CPAを確定
— 成功: 10/2までに確定 / 中止: 出せなければ保留
3. 10/5〜10/18に20万円で訪日客向けに配信
— 成功: CPAが損益分岐以下 /
中止: 損益分岐の1.5倍を超えたら残り30万円は止める
